Este artículo fue publicado originalmente como una guía para instalar Odoo 17 en Ubuntu mediante un script de administración del sistema.

## Qué cubría el tutorial

La guía documentaba la creación del usuario de servicio, la preparación de PostgreSQL, la instalación de dependencias, la descarga de Odoo 17, la configuración de reportes PDF y la creación del servicio de inicio.

## Aviso de seguridad y vigencia

El script completo se conserva sin cambios en el [archivo histórico del repositorio](https://github.com/israelubeda/israelubeda.github.io/blob/master/_posts/2023-12-03-Script-Odoo-17.md), pero no se reproduce en esta página.

Contiene operaciones administrativas y versiones específicas de Ubuntu, PostgreSQL, Python y otras dependencias. Un antivirus local también bloqueó correctamente el HTML que reproducía esas instrucciones como una secuencia ejecutable. Antes de reutilizar cualquier parte, compárala con la documentación oficial de Odoo y pruébala únicamente en un entorno aislado.

La fecha, el título y el permalink original de este artículo se mantienen para no romper enlaces históricos.
